## 🎬 Comment utiliser la Bibliothèque

### Étape 1 : Ouvrir la page
Allez sur : **https://gxo-moissy-v2.pages.dev/bibliotheque**

### Étape 2 : Filtrer les procédures GXO
- Regardez en haut de la page
- Trouvez le bouton **indigo** "GXO Procédures (38)"
- Cliquez dessus

### Étape 3 : Voir un document
- Trouvez le document que vous cherchez (ex: "Création TU")
- Cliquez sur le bouton **"👁️ Aperçu"**
- Le PDF s'ouvre dans une modal

### Étape 4 : Télécharger (optionnel)
- Dans la modal, cliquez sur **"📥 Télécharger"**
- Le PDF se télécharge sur votre ordinateur

### Étape 5 : Rechercher
- Utilisez la barre de recherche en haut
- Tapez un mot-clé (ex: "création", "anomalie", "stock")
- Les documents correspondants s'affichent
